# Plan 1 — Verificación de kilopass y base de la app — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar funcionando la app base: inicio de sesión, panel de administración de usuarios, documentos por usuario con editor TipTap y autoguardado, y exportación a `.docx` y PDF. Antes de eso, confirmar con un script qué ofrece kilopass.

**Architecture:** FastAPI renderiza las páginas con Jinja2 + HTMX. El editor es TipTap cargado como módulos ES desde CDN. MySQL se accede con SQLAlchemy 2 y las migraciones van con Alembic. Cada módulo (`auth`, `usuarios`, `admin`, `documentos`, `exportar`, `web`) tiene una sola responsabilidad. Las rutas obtienen el usuario solo de la sesión.

**Tech Stack:** Python 3.12 (con `uv`), FastAPI, Uvicorn, Jinja2, HTMX, TipTap 2, SQLAlchemy 2, PyMySQL, Alembic, pydantic-settings, argon2-cffi, itsdangerous (SessionMiddleware), python-multipart (formularios), cryptography (autenticación de PyMySQL con MySQL 8), python-docx, LibreOffice headless, openai (SDK), pytest + httpx.

**Spec:** `docs/superpowers/specs/2026-10-31-editor-documentos-legales-design.md`. Este plan cubre los pasos 1 y 2 de su sección 12. Los pasos 3 a 7 (conocimiento, agente A/B/C, despliegue) irán en planes posteriores.

## Global Constraints

- **Python 3.12** exactamente (`requires-python = ">=3.12,<3.13"`). El entorno se crea y sincroniza con `uv sync`; `uv.lock` se versiona.
- **Código y textos en español:** identificadores de dominio, mensajes de interfaz y mensajes de commit.
- **Nombre del producto de referencia:** nunca aparece en código, comentarios, commits ni archivos.
- **Secretos:**
  - solo en `.env`, que git ignora;
  - toda variable nueva se agrega vacía a `.env.example`.
- **Base de datos:**
  - MySQL 8, conexión `mysql+pymysql://…?charset=utf8mb4`;
  - las pruebas corren contra `MYSQL_TEST_DATABASE`, nunca contra `MYSQL_DATABASE`.
- **Aislamiento:**
  - toda consulta de documentos filtra por el `usuario_id` de la sesión;
  - un recurso ajeno o inexistente responde **404**;
  - las rutas de admin responden **404** a quien no es admin.
- **Contraseñas:**
  - se guardan como hash Argon2 (`argon2-cffi`);
  - longitud mínima de 8 caracteres.
- **Correos:** se normalizan con `strip().lower()` al crear y al iniciar sesión.
- **Cookie de sesión:** firmada con `SECRET_KEY`, `HttpOnly` y `SameSite=Lax`.
- **Usuarios desactivados** (`activo = False`): no pueden iniciar sesión y sus sesiones abiertas dejan de valer en la siguiente petición.
- **Un administrador no puede desactivarse a sí mismo.**
- **Contenido del documento:**
  - es el JSON de TipTap con raíz `{"type": "doc", ...}`;
  - el documento vacío es `{"type": "doc", "content": []}`;
  - tamaño máximo de 2 MB.
- **Títulos:**
  - de 1 a 200 caracteres tras `strip()`;
  - el valor por defecto es `"Documento sin título"`.
- **Autoguardado:** el editor manda un `PUT` 2 segundos después del último cambio.
- **PDF:**
  - una sola conversión de LibreOffice a la vez, con tiempo límite de 60 s;
  - si falla, el `.docx` sigue disponible.
- **Rutas en plantillas:** nunca usar `url_for` hacia rutas de tareas posteriores; en ese caso, usar hrefs literales.
- **Rutas de archivos en código:** siempre relativas a `Path(__file__)`, nunca al directorio de trabajo.
- **Servicios:** toda función de servicio que escribe hace `db.commit()`, porque las pruebas escriben con una sesión y leen con otra.
- **Commits:** un commit y un push al final de cada tarea. Cada mensaje termina con las líneas de atribución que indique la sesión.

## Review Focus

1. **Nodos de TipTap desconocidos** (por ejemplo, `blockquote`, `table` o `codeBlock` pegados desde otro lado): la exportación no falla y escribe su texto como párrafos. → Task 8, `test_nodos_desconocidos_se_exportan_como_texto`.
2. **Documento vacío** (`{"type":"doc","content":[]}` o sin la clave `content`): se exporta un `.docx` válido. → Task 8, `test_documento_vacio`.
3. **Título con acentos, ñ y caracteres raros** (`Contrato — Ñandú / 2026`): la descarga funciona y el nombre del archivo se conserva legible (`filename*` RFC 5987, sin `/`). → Task 9, `test_nombre_archivo_con_acentos`.
4. **Correo con mayúsculas o espacios** (`" Ana@Ejemplo.COM "`): inicia sesión igual que `ana@ejemplo.com`, y crear el mismo correo con otra capitalización se rechaza como duplicado. → Task 3, `test_email_se_normaliza`; Task 5, `test_admin_rechaza_email_duplicado`.
5. **Autoguardado con contenido malformado o enorme** (JSON sin `type: "doc"`, cuerpo mayor a 2 MB): responde 422 o 413, nunca 500, y el contenido guardado no cambia. → Task 6, `test_contenido_invalido_no_se_guarda` y `test_contenido_demasiado_grande`.

  - `ErrorConversionPDF(Exception)`.
  - `docx_a_pdf(docx: bytes, timeout: int = 60) -> bytes`:
    - ejecuta `soffice --headless --convert-to pdf --outdir <tmp> <tmp>/doc.docx` con `subprocess.run(timeout=…)`;

  - `disposicion_adjunto(titulo: str, extension: str) -> str`:
